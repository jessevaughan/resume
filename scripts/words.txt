# Words scripts/lib/prose.mjs accepts that a dictionary doesn't know.
#
# One word per line, "#" starts a comment. Casing here is canonical and is
# enforced: with "AdRoll" on the list, "Adroll" in the copy is a finding. That
# is the point of the file as much as the spelling is, because brand casing is
# the error a spell checker would never catch on its own.
#
# Add a word only after reading it. A typo that lands here is invisible to the
# check from then on, which is the one way this guardrail can be defeated.
#
# Hyphenated and slashed compounds don't belong here: the tokeniser splits
# "in-house" and "CI/CD" into their parts, so the parts are what get checked.
# Anything containing a digit is skipped entirely ("GA4", "$3,600").
#
# Seed and audit this list with `npm run prose -- --list`.
